## Run locally
Open `index.html` in any modern browser. The styling is in `style.css` and the profile image is `profile.jpg`.

## GitHub Pages
1. Create a GitHub repository (for example `python-lab-portfolio`).
2. Upload `index.html` and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your public Pages URL.
